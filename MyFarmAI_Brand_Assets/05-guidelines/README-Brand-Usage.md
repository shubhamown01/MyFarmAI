# MyFarm AI — Brand Assets Pack

## Brand lock
- `MyFarmAI_Final_Logo_LOCKED.png` is the user-approved final logo. Do not redesign, recolor, crop, or replace it without explicit authorization.
- `MyFarmAI_AppIcon_Master_LOCKED.png` is the generated app-icon master derived from the approved identity.
- All resized exports preserve the supplied artwork; they are delivery-size variants, not new logo designs.

## Included
1. Final logo master (original PNG, unchanged)
2. App-icon master (original PNG, unchanged)
3. Web-friendly logo exports (PNG widths, WebP, JPEG)
4. Android/general app icon sizes (48–512 px)
5. iOS/general app icon sizes (60–1024 px)
6. Favicon PNGs and multi-size ICO
7. Social/marketing logo export and 1200×630 Open Graph preview
8. This usage guide

## Recommended placement
- Website navbar: `01-brand-logo/web/myfarm-ai-logo-800px.png` or WebP
- Website footer: approved logo on a white/light background; do not invert or recolor without approval
- Browser favicon: `03-favicon/favicon.ico`
- Android launcher: start with `02-app-icon/android/myfarm-ai-icon-512.png`; configure platform-specific adaptive-icon layers in the app project if required
- iOS/general icon: `02-app-icon/ios/myfarm-ai-icon-1024.png`
- Social link preview: `04-social-and-marketing/og-image-1200x630.png`

## Important technical note
These are raster image assets (PNG/JPEG/WebP/ICO), not editable vector SVG masters. The current approved logo artwork was supplied as a raster image, so no SVG has been fabricated. Android adaptive-icon foreground/background layers and an editable vector source should be prepared separately if the app build specifically requires them.
