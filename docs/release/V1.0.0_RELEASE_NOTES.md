# MyFarmAI v1.0.0 — Release Notes

**Release date:** 2026-11-09 (release candidate; publication pending owner approval)
**Application ID:** `com.myfarmai.android` · **versionName:** `1.0.0` · **versionCode:** `1`
**Minimum Android:** check `/data/MyFarmAI/android/android/gradle.properties` → `minSdkVersion` (see install section)
**Production web:** https://myfarmai-web-zwpytbwu.onslate.in
**Production backend:** https://myfarmai-backend-50047414881.development.catalystappsail.in
**Official download (after publication):** https://github.com/shubhamown01/MyFarmAI/releases

## New features
- Email-OTP authentication with opaque session cookies, refresh-token rotation and reuse detection.
- Farmer profile, farms, land plots/boundaries (E5) persistence on first-party management PostgreSQL (Neon).
- Crop plans with revisions (P7B) and per-user dashboard.
- Weather (Open-Meteo: non-commercial free tier) and web research with citations (SearXNG).
- AI chat assistant with per-user usage counters (20/day, 10/hour) and cloud-only model paths.
- Feedback submission (bug/feature/question/praise) — anonymous, optional reply email.
- **Update-check API** (`GET /api/v1/app-updates/latest`) that reports the latest release version, minimum supported version and severity. **No client consumes it yet** — the Android app has no Settings/About screen and no update prompt, so updates are announced on the download page and the GitHub release.
- Public APK download at `/api/v1/downloads/app-release.apk` (backend, ≥ v0.9 of the backend contract).

## Improvements
- Same-origin web proxy for API so the dashboard is fully reachable from the deployed front-end.
- Version metadata unified (`VERSION` file + all manifests at 1.0.0).
- CI gates on PRs/pushes: backend lint/format/pytest, web typecheck/jest/lint/build, Android checks.

## Fixed bugs
- Feedback submissions previously wrote a random UUID into `user_id`, violating the FK on PostgreSQL (SQLite tests do not enforce FKs). Anonymous submissions now store `user_id = NULL`.
- Migration chain bug: feedback migration forked an extra Alembic head (wrong `down_revision`), producing 2 heads and blocking startup against an older image; re-chained to `c8d9e0f1a2b3`, file/revision renamed to `f4b2c3d4e5a7_fb_feedback1` (fits varchar(32) `alembic_version.version_num`).
- Migration file previously omitted the explicit `id` primary key column (model-injected via UUIDMixin is not emitted by `op.create_table`).

## Security changes
- Production backend now served with `ENVIRONMENT=production`, pinned `ALLOWED_HOSTS`, `CORS_ALLOWED_ORIGINS`, `TRUSTED_PROXY_CIDRS` (10/8, 172.16/12, 192.168/16), and `PUBLIC_DIR` for the official APK asset.
- Session cookie now `Secure`; CSRF middleware; rate limiting with a trusted-proxy-safe client IP source (X-Forwarded-For spoofing earlier bypass documented and fixed upstream in the deploy image configuration).
- Signed release build now uses the production gradle configuration (NOT the debug keystore) — signature identity preserved across 1.x updates (see `./ANDROID_SIGNING_AND_KEY_RECOVERY.md`).

## Known limitations
- Registration with OTP is BLOCKED until real SMTP is configured; new users must use owner-provisioned test accounts (or owner flips SMTP).
- **Onboarding cannot be completed by a self-registered account.** The wizard's `verification` step requires `verification_status` of `active`/`verified`, but no web or Android client can submit the selfie and there is no approval endpoint yet (audit finding MFAI-025). Until that is resolved, onboarding stays at the verification step.
- No in-app update prompt. The update-check API exists, but the app has no Settings/About screen to surface it.
- Google Play listing not available; APK is direct-download (sideload). Android may require "Install unknown apps" (from the browser) — see below.
- Full pg_dump task automation pending; only the manual Neon-consoled procedure is guaranteed.
- The fine-grained real-device (F/G) check and the mobile layout (M) are pending an actual handset.

## Database migration notes
- The DB is at Alembic head `f4b2c3d4e5a7_fb_feedback1` (live on Neon).
- New `feedback` table: id (uuid PK), user_id FK → users.id ON DELETE SET NULL, email, category, message, app_version, created_at, updated_at, index `ix_feedback_user_id`.
- No data loss encountered on this release path; migration is a forward-only add.

## Upgrade instructions
- No previous public version exists — this is the initial public release.
- After installing, the version is visible in Android's app info (Settings → Apps →
  MyFarmAI). There is no in-app Settings/About screen and no update prompt; check the
  official download page or the GitHub release for newer versions.

## Install (direct APK)
1. Download from the official release page (see link above) — **verify the
   SHA-256 checksum** below before installing.
2. Open the APK. If Android blocks "install from unknown sources", enable it
   for the browser you used (Settings → Apps → Special access → Install unknown apps).
3. Open MyFarmAI AI. It targets the production HTTPS backend automatically.
